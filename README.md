# Compresso

**Cut Claude Code & Codex token costs. Local-first. Honest numbers.**

This is the public releases repository for [Compresso](https://compresso.ai) — the macOS app that sits between your AI coding agents and their APIs, trimming redundant context before it costs you money.

## Download

**[Download the latest release for macOS (Apple Silicon)](https://github.com/armanzeroeight/compresso/releases/latest)** — requires macOS 14+.

Every release here is code-signed, notarized by Apple, and carries a signed auto-update manifest — the app keeps itself up to date after the first install.

## What's here

- **Releases + changelogs** for every version
- The auto-updater manifests the app consumes (`latest.json`)

The application source is developed in a private repository; this repo is the distribution and release-notes surface.
